### Data mapping
The real pipeline schema differs from the design mockup:
- `cluster.signature` → cluster ID
- `cluster.basis.message_template` → cluster name (cleaned)
- `cluster.incident_types[0]` → cluster type
- `cluster.affected_hosts` → list of host IDs
- `cluster.first_seen` vs `fleet.generated_at` → derives "new" vs "ongoing" status (within 24h = new)
- `top_hosts` has: `host_id`, `severity`, `incident_types`, `incident_count`, `last_event_ts` (no `user_id`)
- `user_id` is available in individual timeline.json files

- **Workshop scene**: Uses the same meadow dawn-horizon stripe; the reference design had a separate workbench/pegboard scene from `scenes.jsx`. The WorkshopStripe is HTML with absolute-positioned icons which doesn't translate cleanly to a Python string; the meadow stripe is visually coherent even for the Workshop tab
- **Dark mode**: Not implemented (the CSS has the tokens defined but no toggle UI)
